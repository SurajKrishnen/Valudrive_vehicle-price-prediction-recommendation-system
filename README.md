# Vehicle Price Prediction & Recommendation System

Phase 1: Price Prediction Model

## Run
1. Install dependencies:
   pip install -r requirements.txt
2. Train:
   python train_model.py

Dataset: Car details v3.csv
Models compared: Linear Regression, Decision Tree Regressor, Random Forest Regressor.
Evaluation: MAE, RMSE, R².
The best model is saved to models/price_model.pkl.
